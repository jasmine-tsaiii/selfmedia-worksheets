你填的內容只存在這台裝置的瀏覽器裡，不會上傳到任何地方，要用同一個瀏覽器打開才會看到。換裝置或清除瀏覽資料就會消失，請定期按「下載備份」。會談前，也可以按「複製全部文字」或「下載文字檔」傳給老師。

列印成 PDF：文字可以選取複製，檔案也比較小

  1. 按下面的「開啟列印視窗」。
  2. 電腦（Chrome、Edge）：「目的地」選「另存為 PDF」，按「儲存」。
  3. Mac 的 Safari：左下角的「PDF」選單選「儲存為 PDF」。
  4. iPhone、iPad：在預覽縮圖上用兩指放大，再按分享，選「儲存到檔案」。
  5. Android 的 Chrome：「選擇印表機」選「儲存為 PDF」，再按下載圖示。

如果你是在 LINE、IG 或 Claude 這類 App 裡面開的，可能沒有列印功能，或檔名會不對。請改用 Chrome 或 Safari 打開，或改按「下載 PDF」。
