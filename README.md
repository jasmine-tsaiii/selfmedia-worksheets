# 自媒體陪跑學習單

三個月自媒體陪跑的每週學習單，單一 HTML 檔，不需要安裝任何東西。

- 學員填寫的內容只存在自己的瀏覽器（localStorage），不會上傳到任何伺服器
- 可以複製全部文字、下載 PDF、下載文字檔（.md）、下載與匯入備份（.json）
- 「下載 PDF」會直接產生 PDF 檔，檔名例如「第2堂課學習單-20261031.pdf」；PDF 內含所有分頁的填寫內容（文字是圖片，不能選取複製；要複製請用「複製全部文字」）。如果載入失敗會改用列印視窗
- 「列印成 PDF（可複製文字）」會先顯示各裝置的操作步驟，再開啟列印視窗；產生的 PDF 文字可以選取複製
- 首頁是「總覽」：每堂課的入口、填寫進度、三個月地圖
- 每堂課一個資料夾：`lesson1/`、`lesson2/`…，每頁上下都有「回到總覽」與上下堂的連結

## 線上網址

## 內容

| 資料夾 | 主題 |
|---|---|
| `lesson1/` | 第 1 堂課：起點、市場觀察與定位 |
| `lesson2/` | 第 2 堂課：受眾與修正定位（會自動帶入第 1 堂寫的定位 v0，需用同一個瀏覽器） |
| `lesson3/` | 第 3 堂課：人設與帳號門面（含「用 AI 試試」：複製 prompt 時會帶入第 2 堂與本堂已填的內容） |

## 破關系統

- 首頁是「破關地圖」：13 週 = 13 關，三個月 = 三個世界；只顯示已破關數、目前在哪一關、每關三顆星。（11/11 精簡：拿掉徽章牆、稱號、總 XP）
- 每一堂是流程闖關：步驟條 → 每個任務完成打勾 → 全部必填完成就破關，有星星與慶祝動畫。
- 只有標「必填」的題目算破關；選填題收在「＋ 選填」摺疊裡。週日回報與「用 AI 試試」都是選填，不影響破關。沒破關也沒關係，頁面上有明講。
- 進度與星星都存在學員自己的瀏覽器（localStorage），不會上傳。
- 右下角有淺色/深色切換鈕（選擇會記在瀏覽器裡）。
- 各堂的題目寫在 `lessonN/index.html` 的 `COURSE`（欄位加 `optional: true` 就是選填）。
- 頁尾是收合的「隱私小說明」加上版權字樣。
