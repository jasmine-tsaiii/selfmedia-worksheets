# 自媒體陪跑學習單

三個月自媒體陪跑的每週學習單，單一 HTML 檔，不需要安裝任何東西。

- 學員填寫的內容只存在自己的瀏覽器（localStorage），不會上傳到任何伺服器
- 可以複製全部文字、下載文字檔（.md）、下載與匯入備份（.json）
- 每堂課一個資料夾：`lesson1/`、`lesson2/`…

## 線上網址

https://jasmine-tsaiii.github.io/selfmedia-worksheets/

## 內容

| 資料夾 | 主題 |
|---|---|
| `lesson1/` | 第 1 堂課：起點、市場觀察與定位 |
| `lesson2/` | 第 2 堂課：受眾與修正定位（會自動帶入第 1 堂寫的定位 v0，需用同一個瀏覽器） |
